🧮 MathSphere

Explore Mathematics. Expand Your Mind.

MathSphere is an interactive mathematical website that helps users solve problems, perform calculations, visualize graphs, and learn mathematical concepts in one place.

✨ Features

🧮 Scientific Calculator

🔢 Number System Converter

📊 Matrix Calculator

📐 Linear and Quadratic Equation Solver

📈 Mathematical Graph Plotter

🧠 Interactive Math Quiz

📚 Learning Hub with Tutorials

🌙 Dark and Light Mode

📱 Responsive User Interface

🛠️ Technologies Used

HTML5

CSS3

JavaScript

KaTeX (LaTeX Mathematical Notation Engine)

🚀 How to Run

Clone the repository:

git clone https://github.com/kavyakrishna707/MathSphere.git

Open the MathSphere folder in VS Code.

Open index.html in your browser, or run it using the Live Server extension.

🎯 Project Objective

The goal of MathSphere is to make mathematics easier, more interactive, and enjoyable by combining mathematical tools and educational resources in a single platform.

🌐 Deployment

MathSphere is a static website that runs directly in a web browser without requiring a database or backend server. It can be hosted using GitHub Pages or other static hosting services.
